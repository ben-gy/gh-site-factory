# Build Log: Shark Incidents (au-sharks)
**Date:** 2026-07-28
**Status:** deployed

## Idea Source
Researched. IDEAS.md was empty. The catalog (55+ sites) is heavy on ABS/gov-transparency
economic and demographic data; I searched for a genuinely new domain and confirmed data
accessibility. Rejected GrantConnect grants (data.gov.au entry links to a login-gated
report) and ACCC product recalls (no clean machine-readable feed). Chose the **Australian
Shark-Incident Database (ASID)** — a fully public, MIT-licensed, browser-reachable dataset
on GitHub + Zenodo (no login, no key), 1,196 incidents 1791–2022 with real coordinates,
species, activity and outcome. It opens a domain the catalog had nothing in (wildlife /
marine safety), has strong public search interest, and supports a real map plus rich
temporal/categorical views.

## Site Details
- **Name:** Shark Incidents
- **Repo:** ben-gy/au-sharks
- **Category:** data-explorers
- **Audience:** Australian beachgoers, surfers and divers wanting realistic risk context;
  journalists and researchers; the shark-curious.
- **Stack:** Vanilla TypeScript + Vite + Vitest; Leaflet for the map.
- **Data strategy:** pipeline, annual cron (`23 6 9 3 *`). ASID publishes a refreshed
  public version roughly once a year — annual is the slowest proportional cadence and it
  matches the source. Embeds the data year range (1791–2022), not a run timestamp, so
  re-runs are idempotent.

## Data Sources
- Australian Shark-Incident Database — github.com/cjabradshaw/AustralianSharkIncidentDatabase
  (data/injurydat.txt; MIT; Riley et al. 2022, Scientific Data 9:378,
  doi:10.1038/s41597-022-01453-9). Maintained by Taronga Conservation Society Australia with
  Flinders University and NSW DPI.
- ABS ASGS 2021 state/territory boundaries (vendored pipeline/au-states.geojson; CC BY 4.0).

## Architecture Decisions
- Vanilla TS: single-page dashboard with a map and drawers — no need for React.
- Pipeline emits one clean `incidents.json` (~1,200 records, 324 KB) + `meta.json` +
  vendored `boundaries.geojson`; the browser derives every aggregation client-side (one
  source of truth beats duplicating rollups).
- Two reconciliation gates on independently-recorded fields: ≥98% of geolocated incidents
  inside Australia's bbox (99.7% actual), and ≥90% agreement between the recorded State and
  a coordinate→state classifier (99.2% actual). Both catch column shifts/lat-lng swaps; the
  tests deliberately swap and rotate columns to prove the gates fail loudly.
- Semantic outcome colour scale (fatal red / injured amber / uninjured teal) used across
  every view; species and state colours defined once, referenced everywhere.
- Signature story = the falling fatality rate (more incidents, fewer deaths), told in the
  Overview hero, the Over-time view, and Insights.
- Tone: calm, science-led, conservation-and-safety framing — deliberately not sensational.
