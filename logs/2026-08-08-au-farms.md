## Architecture Decisions

**Vanilla TS over React.** Eight views, one shared drawer, hash routing. No component tree deep
enough to earn a framework.

**Hand-rolled SVG over a charting library.** The encodings this site needs — an outline-only mark for
a weak estimate, a line that *breaks* at a year ABARES did not publish, a comparison connector that
goes neutral when the difference is smaller than the survey error — are exactly what chart libraries
make hard. A hygiene test fails the build if a charting dependency is added.

**The evidence tier is computed once in the pipeline, not in the views.** Median RSE is 28%, 54.3% of
cells exceed ABARES' own "use with caution" threshold, and some region-years rest on five surveyed
farms. Every value gets a five-tier grade — the worse of an RSE ladder and a sample-size ladder — and
the tier changes how the mark is drawn. There is no switch to turn it off.

**The rate-of-return series is used as published and never re-derived.** `profit ÷ capital` fails to
reproduce ABARES' own series in 20–56% of region-years depending on the denominator. A hygiene test
greps for that division.

**`pipeline/parse.mjs` has no dependencies and reads no files** so the tests import it directly, with
a `parse.d.mts` for type checking. This is the documented fleet CI trap.

## Findings, and one that survived an attempt to kill it

Summed over the 35 settled years, per surveyed broadacre farm: **$2,670,290 from farming** against
**$8,087,350 from land appreciating** — roughly three quarters of the long-run return to farm capital
is the asset, not the activity. Cross-checked by a second method (mean of the 36 published annual
rates: 1.19%/yr excluding land vs 4.02% including it → 70.3%).

**The refutation attempt made it stronger, and corrected the design.** The design phase specified a
gate asserting that re-basing to a 2013 start would give a *materially lower* share. Testing it
showed the opposite — 77.1% from 2013 against 75.2% from 1990, with every start year from 1990 to
2020 landing between 73.4% and 82.4%. Shipping the gate as specified would have failed the build on a
false premise; it now asserts start-year **robustness**, which is both true and a stronger claim.

**Zone finding, stated carefully.** Mean return excluding appreciation is 0.05%/yr across the 8 High
Rainfall regions vs 1.71% Wheat-Sheep and 1.94% Pastoral — but land appreciates at a broadly similar
2.1–2.8 points in all three. High Rainfall's ~98% land share is because its farming earns almost
nothing, *not* because its land rose faster, and the site says it that way.

## Reconciliation gates: 23/23 pass

Three are unusual and worth naming:

- **One asserts a FAILURE.** The naive `profit at full equity = business profit + interest + rent`
  identity must keep failing in ≥30% of region-years (it fails in 38.4%), so the deliberately broken
  accounting joint cannot be quietly "fixed" into a claim by a future edit. A gate that only ever
  asserts success cannot protect a deliberate absence.
- **One asserts the headline survives its own refutation** (the start-year band above).
- **One asserts the negative-RSE trap still exists in the source.** Raw RSE reaches −4,266 where the
  estimate itself is negative; a threshold comparison without `|RSE|` would mark the noisiest cells in
  the file as the most reliable. Validating the guard where the failure actually lives.

## Errors & Resolutions

**1. The Data Pipeline failed on its first CI run.** `agriculture.gov.au` hung on every retry from a
GitHub runner while the identical code fetched all five files in seconds locally — the `au-worksafe`
failure pattern, which was previously resolved by deleting the cron. Here it was fixed instead:
browser-shaped headers including the `Sec-Fetch-*` set, an explicit 120s `AbortController`, and
`NODE_OPTIONS=--dns-result-order=ipv4first` (the CDN black-holes IPv6 from datacentre ranges, so the
request hangs to the timeout rather than refusing). The re-run downloaded all five files in under a
second each, ran aggregate and all gates, and was **idempotent** — "Everything up-to-date", CI
regenerated byte-identical data.

**2. The view specs never reached the implementation agents.** The eight view-building agents were
passed their design specs as a JSON *string* rather than an object, so each received `undefined` and
designed its own view. The shipped set is better balanced than the specified one — the original had
two matrix-shaped views, no physical-production view, and two proposals that duplicated each other —
but it is **not** the set the design phase chose. `plan.md` records the built set and says so
explicitly rather than pretending the plan was followed.

**3. The headline originally included the provisional year.** The aggregator summed all 36 years,
including 2025, which the site's own stated rule forbids. An implementation agent caught it. The
totals now cover the 35 settled years and the provisional year's contribution is reported separately
rather than folded in; a gate and a test now enforce the exclusion and reconcile it exactly.

**4. Two views leaked internal route ids as headings.** "Ground" and "Trails" were rendering as
user-facing `<h1>` text. Renamed to "Where farming pays" and "Yield trails".

**5. A hard-coded number in the About copy was wrong.** It asserted "269 region-years" of falling
land; 269 is the count of land-*value* falls, while capital appreciation went negative in **277**.
Now computed at build time — two plausible numbers in one sentence with no way to tell them apart by
eye is exactly the sort of thing that must be derived, never typed.

**6. A verification false alarm worth recording.** Real trusted clicks appeared to do nothing, which
looked like the classic dead-click defect. The cause was my own measurement: the browser tool's click
coordinates are in **screenshot space (800×500)**, not CSS pixels (1440×900), so every click was
landing 1.8× off. Once scaled, every interaction worked. Worth remembering — the symptom is
indistinguishable from a genuinely dead control.

## Honest limitations
- The regional file has **no industry dimension** — every region is all-broadacre combined, so "beef
  in the Kimberley" is unanswerable from this data and is never offered.
- All dollars are **nominal**. The headline is a ratio of two series in the same year's dollars so
  inflation cancels out of it, but no single dollar figure is deflated.
- The size and performance-third files end in **2023 and 2022** against 2025 for everything else.
- `meta.asAt` is a run timestamp, so a future pipeline run will commit a diff even when the data is
  unchanged. Harmless on a yearly cron, but `au-advisers` solved this by embedding the data as-at
  date instead, and this could adopt that.
- Screenshot capture in the browser pane was unreliable while the pane was hidden (stale composites),
  so visual checks leaned on geometry assertions plus the screenshots that did render cleanly.
