## Architecture Decisions
- **Vanilla TS** (not React): a tabbed single-page explorer, no complex component tree.
- **Nominal monthly + real quarterly:** chain volume is only published quarterly and only for Total + 6 major groups (not the 15 leaves), so the Real-vs-nominal view annualises both series to a common quarterly axis and rebases to 100 for an honest dollars-vs-quantity comparison.
- **Embedded ERP** (not fetched): keeps the per-capita denominator off the network path — a factory-endorsed static table — so the pipeline has a single upstream (ABS RT).
- **Two reconciliation gates with an absolute-tolerance floor:** ABS rounds every cell to $0.1m, so small-denominator category/leaf sums drift a few hundred thousand dollars — a large *relative* error that is meaningless. Gates fail only when a discrepancy clears BOTH an absolute floor ($0.6m category / $1.2m state) and a relative threshold; a genuine column shift moves totals by tens–thousands of millions and still trips them.
- **Colour == category everywhere** (6 fixed colours) per the visualization rules; treemap fills by category, growth shown via labels/growthColour on borders and table cells only.

## Errors & Resolutions
- **Gates initially failed** with worstRel 3.33% (category) and checks=0 (state). Root causes: (a) Retail Trade publishes 8 states, not 9 — region 9 "Other Territories" is absent, so the state gate's `haveAll` was never satisfied → fixed STATE_CODES to the 8 states; (b) ABS $0.1m rounding produces large *relative* errors on tiny category/leaf sums → added an absolute-tolerance floor to both gates. Both then pass with 0 failures.
- **Chain volume returned 0 rows** on the first probe — it is published QUARTERLY (FREQ=Q), not monthly; forcing FREQ=M excluded it. Fixed the collect query.
- **TS build errors:** tests were in tsconfig `include` (pipeline .mjs has no types) + three unused imports. Removed tests from the tsc include (vitest typechecks them) and pruned the imports.
- **CI boundary path:** aggregate originally copied the geojson from the factory `patterns/` dir, absent in the deployed repo. Vendored it into `pipeline/au-states.geojson` and read from there so the monthly CI data-pipeline is self-contained.
- **Browser pane:** could not load the LIVE benrichardson.dev URL (blocked by policy) and had an intermittent screenshot repaint glitch; verification therefore ran against the byte-identical local dist (same bundle hash as live), so live behaviour equals verified behaviour.
