# Build Log: Victorian Rents
**Date:** 2026-07-29
**Status:** deployed

## Idea Source
Researched. IDEAS.md was empty. Reviewed the registry (~64 sites, heavily AU open-data
explorers) and the live ben-gy repo list. Looked for a genuinely-new domain: housing sites
existed for **supply** (au-approvals = building approvals, au-planning = development
applications) but nothing for the **price of renting** — the defining cost-of-living topic
and one of the most-searched civic questions ("median rent [suburb]"). Confirmed a clean,
rich source: the Victorian Government's **DFFH Rental Report** (discover.data.vic.gov.au),
which publishes two cumulative time-series workbooks — moving-annual median rents by suburb
(from 2000) and quarterly medians by LGA (from Jun 1999), each split by dwelling type with
lettings counts. Scoped to Victoria (like nsw-pokies) because Victoria publishes by far the
cleanest long, open, count-level rent history.

## Data Sources
- DFFH Rental Report — Moving annual median rents by suburb (discover.data.vic.gov.au dataset `rental-report-quarterly-moving-annual-rents-by-suburb`; XLSX via dffh.vic.gov.au redirects; CC BY 4.0)
- DFFH Rental Report — Quarterly median rents by LGA (`rental-report-quarterly-quarterly-median-rents-by-lga`; CC BY 4.0)
- ABS Consumer Price Index, Melbourne, all groups (data.api.abs.gov.au SDMX dataflow CPI — `1.10001.10.2.Q`; CC BY 4.0)
- ABS ASGS 2024 LGA boundaries, Victoria (geo.abs.gov.au ArcGIS LGA MapServer, `state_name_2021='Victoria'`; CC BY 4.0)

## Architecture Decisions
- **Vanilla TS** — single-page tabbed explorer with one map; no need for React.
- **Cumulative workbooks** — the pipeline fetches only the latest of each dataset (resolved
  via the data.vic CKAN API by newest quarter, with a hard-coded fallback URL) because each
  file already contains the full 26-year history. Two files + one CPI series + one boundary
  fetch.
- **Map at LGA level, suburbs elsewhere** — the DFFH suburb groupings (e.g.
  "Albert Park-Middle Park-West St Kilda") are the report's own aggregations with no official
  boundaries, so the choropleth uses the 79 councils (real ABS polygons) and the 146 suburbs
  drive the finder/rankings/explorer. Stated plainly in the UI and About.
- **Real-rent (CPI) toggle** — the affordability angle: rents rose 244% while Melbourne CPI
  rose 108%, a ~65% real rise. Cleaner and more defensible than an income join.
- **Two reconciliation gates on independently-published total rows** — Metro+Non-Metro ==
  Victoria (742 quarter×type checks, exact), and Σ(councils) == Victoria — so a column shift
  fails the build.

## Errors & Resolutions
- **Boundary name join** — 3 DFFH LGAs (Latrobe, Bayside, Kingston) initially unmatched
  because ABS disambiguates them as "(Vic.)" not "(C)". Broadened `lgaKey` to strip any
  trailing parenthetical → 79/79 matched.
- **TS strictness** — unused imports/vars, `import.meta.env` typing, and `.mjs` module typing
  failed the first `tsc`. Added `src/vite-env.d.ts`, a `tests/shims.d.ts` wildcard `*/parse.mjs`
  declaration, annotated test callback params, removed dead imports. Clean after.
- **Insights render assertion** — the insights view is card-based (no chart/table); relaxed
  the smoke-test "has marks" assertion to accept `.insight` cards.
