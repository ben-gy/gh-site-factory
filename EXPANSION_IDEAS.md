# Expansion Ideas

Ideas for improving existing sites with new data, views, or features. These are NOT new site ideas — they're enhancements to products we've already built. The scheduled task logs these here instead of building duplicate sites.

Review periodically and fold the best ones into the existing repos.

- **au-gov**: User idea "Machinery of Government (AU)" (from IDEAS.md, 2026-07-13) overlaps the deployed au-gov (AGOR federal explorer: 1,381 bodies, 17 portfolios, timeline). The genuinely new parts to fold in as enhancements rather than a duplicate site: (a) **state/territory government structures** — each state's departments/agencies from state government directories (e.g. NSW nsw.gov.au/departments-and-agencies, VIC vic.gov.au, service directories on data.gov.au); (b) **MoG change history** — how Administrative Arrangements Orders (AAOs) have renamed/merged/split federal departments over time (PM&C publishes AAOs at pmc.gov.au/government/administrative-arrangements-orders; a department "family tree" / genealogy timeline view would be a killer feature); (c) **ministers per portfolio** from directory.gov.au (Government Online Directory has a data feed at directory.gov.au/reports/data-files). Any of these could ship as new views inside au-gov.
- **au-pollution**: Add **greenhouse gas emissions** alongside the National Pollutant Inventory's toxic substances. The Clean Energy Regulator publishes NGER (National Greenhouse and Energy Reporting) data for every large emitting facility in Australia — scope 1 and scope 2 emissions in tonnes CO2-e plus energy produced and consumed, annually and free: https://cer.gov.au/markets/reports-and-data/national-greenhouse-and-energy-reporting-data. The **Safeguard Mechanism** dataset adds each covered facility's baseline and whether it exceeded it, which is the newsworthy angle (who is over their limit, and by how much): https://cer.gov.au/schemes/safeguard-mechanism/safeguard-facility-reported-emissions. Considered as a standalone site on 2026-07-22 and rejected under the expansion rule — it is the same *shape* as au-pollution (facility-level emissions, map, treemap, rankings) and would read as "the same site with different numbers". As views inside au-pollution it is genuinely additive: a CO2-e mode on the existing facility map, a baseline-vs-actual column, and a cross-reference of which NPI facilities are also Safeguard-covered (join on ABN/facility name).
- **au-baby-names**: The deployed site covers NSW (1952–2025) and Queensland (1960–2025) — the two states that publish long, open, count-level baby-name histories. Add more states to make it genuinely national: **South Australia** publishes 1944–2024 (data.sa.gov.au dataset `popular-baby-names`, a `baby-names-1944-2013.zip` plus per-year files 2015+ with inconsistent names like `top100names_male_2024.csv` vs `male_cy2023_top100.csv` — resolve via CKAN by matching year+gender in the resource name, and add a minimal stored/deflate zip reader to pipeline/parse.mjs). Victoria and WA publish only short/rank-only or PDF top lists (no open count history) so they can't join on equal footing — note that honestly if added. Folding SA in as a third `state` in the existing pipeline (it already normalises three source shapes into one record stream and derives ranks) would light up a real three-way State face-off and strengthen the "national fashions" claim without a new site. Considered as part of the 2026-07-28 build and scoped down to NSW+QLD for reliability.
- **au-contracts**: The deployed site covers FY2023-24 + FY2024-25 (period 2023-07-01 → 2025-06-30) with a consulting-spend and tender-method focus. The just-completed **FY2025-26** (1 Jul 2025 – 30 Jun 2026) is now fully available from the AusTender OCDS API and is NOT in the site — the pipeline window is fixed and won't roll forward on its own. Enhancement: add FY2025-26 (roughly 57k contracts / ~$87B) so the year-over-year view runs through the newest year, and make the pipeline window advance automatically each 1 July (e.g. "most recent complete FY"). API: `https://api.tenders.gov.au/ocds/findByDates/contractPublished/{startISO}/{endISO}` — paginate via `links.next` cursor, dedupe amendments by base CN number (strip `-A\d+` suffix), classify by UNSPSC 2-digit segment. (A duplicate single-year FY2025-26 build was attempted on 2026-07-12 after a worktree recycle; folded here instead of shipping a second site.)

- **au-vehicles**: Add a **recalls-per-vehicle-on-the-road rate by make**, a metric neither dataset can produce alone. au-vehicles already carries fleet counts by make from BITRE Road Vehicles Australia; the Australian Government Vehicle Recalls register adds an "affected units" integer per recall across 5,527 recalls back to 9 July 1986, CC BY 4.0. Server-rendered listing with a plain pager, verified HTTP 200: `https://www.vehiclerecalls.gov.au/recalls/browse-all-recalls?page=N` (20 rows/page, last page 276), detail pages at `/recalls/rec-NNNNNN` carrying `field--name-field-r-*` classes (r-make, r-models, r-date-ranges, r-affected-units, r-defect, r-hazard, r-action, plus a downloadable per-recall VIN CSV). TRAP: `vehiclerecalls.gov.au/search` sits behind an Akamai bot interstitial that returns HTTP 200 with a challenge body — the `browse-all-recalls` path on the same host is unprotected; use only that. Considered as a standalone recalls site on 2026-08-02 and rejected under the expansion rule: the ACCC consumer-product register (8,044 recalls) has no bulk file at all and would need ~13,600 HTML detail fetches, and geography across the whole corpus is a mirage ("Nationally"/"Online", not states), so it cannot carry the map-led format on its own. As a rate column inside au-vehicles it is genuinely additive. Do NOT touch the TGA DRAC recall export despite it being the cleanest bulk file of the lot — tga.gov.au copyright forbids commercial use and re-transmission without written approval, and the export's own footer row says so.

  **CORRECTION (2026-08-06):** the premise above — that the ACCC consumer-product register "has no bulk file at all and would need ~13,600 HTML detail fetches" — is now disproven, and this entry should be worked from the revised facts. The **paginated RSS feed IS a complete bulk spine**: `https://www.productsafety.gov.au/rss/recalls.xml?page=N` walks the entire archive at a hard 25 items/page (`items_per_page` is silently ignored) — page=0 is today, page=320 reaches 22 Sep 1999, page=340+ returns empty. 340 requests = 24 MB = **8,197 unique GUIDs spanning 28 Jul 1986 to today**, with zero XML parse errors and no rate-limiting observed. Licence is explicit CC BY 4.0 (https://www.productsafety.gov.au/about-us/using-our-website/disclaimer-and-copyright, attribution "Source: ACCC © Commonwealth of Australia"), and the feed updates daily. The RSS row alone carries title, stable UUID, published date, a 109-term two-level category path, and hazard/defect/consumer-action free text; supplier, PRA number, states, sale dates and manufacturer country still need the detail page. TWO TRAPS: (1) **1,477 of the 8,197 detail URLs (18%) are retired stubs that return HTTP 200 with a full body from a DIFFERENT page** — 1,376 land on the FSANZ "Australian food recall alerts" index and 101 on the DITRDCA vehicle-recalls site — so a naive scraper keyed on `<h1>` invents 1,376 identically-titled recalls; detect by ABSENCE of the string `field-psa-recall-published-date`, never by status code, and exclude them from every supplier/state/country denominator. (2) Supplier is free text and must be normalised — "Kmart Australia Ltd" / "Ltd." / "Limited" are three strings, so a leaderboard is wrong by ~2x without it (4,074 raw distinct → 3,558 normalised). Reconciliation anchor: the ACCC 2023-24 annual report states "we also published 264 voluntary recalls" against 261 computed from the feed (98.9%). A publishable finding sits in it: **button-battery recalls run 11.3/yr before the 22 June 2022 mandatory standards and 48.8/yr after — 1 in 4 of all 2026 recalls.** The earlier objection still stands on its own terms, though: 5,274 of 6,636 location-tagged recalls are simply "Nationally", so the geography remains a mirage and this is still an au-vehicles column rather than a map-led site of its own.

- **nemwatch**: Add a **retail electricity plan archive** alongside the wholesale spot prices. The Consumer Data Right energy endpoints are genuinely public, keyless and CORS-open — the register at `https://api.cdr.gov.au/cdr-register/v1/energy/data-holders/brands/summary` lists every retailer brand, and each retailer's `GET /energy/plans` (requires an `x-v` version header) returns their full market offer set; ~17,491 plans were counted live on 2026-08-03. Considered as a standalone site that day and rejected for three reasons: it would duplicate the AER's own Energy Made Easy comparison tool, the retailer-submitted plan content is explicitly carved out of the AER's CC BY 4.0 (the AER states it is "prevented by law and regulations" from broadly sharing it), and — decisively — it has **zero history**, so the only real differentiator accrues months after launch. Getting a "cheapest plan" calculation wrong also carries real consumer-harm risk. As an addition to nemwatch it is genuinely additive and avoids the duplication problem: snapshot the plan set on the existing cron and build the value proposition nobody else has — *how retail offers move over time, and how they track the wholesale prices nemwatch already shows*. Store only aggregates (median/spread of standing vs market offers per network region), never a "switch to this plan" recommendation.

- **au-trade**: Add a **seafood commodity slice**. ABARES *Australian fisheries and aquaculture statistics* (Tables 13–18: export/import value and volume by commodity 1989-90 onward, plus trade by country) covers the same ground au-trade already models from ABS merchandise trade. Surfaced on 2026-08-08 while researching a standalone "Seafood" site and rejected under the expansion rule — the trade half is au-trade's shape with different numbers. The genuinely new material in that workbook is *production* (wild-catch vs aquaculture by species and jurisdiction, 1998-99 → 2023-24), which carries a real finding: **farmed salmonids alone were worth $1,294,977,000 in 2023-24 — more than the entire wild-catch output of all seven state and territory fisheries combined ($1,168,949,300), and more than 3× every Commonwealth-managed fishery put together ($402,732,800); aquaculture is now 58.3% of Australian seafood production value, up from 28.7% in 1998-99.** TRAP: the workbook URL is a rotating SirsiDynix asset id and must be scraped from the landing page each run (`https://www.agriculture.gov.au/abares/research-topics/fisheries/fisheries-and-aquaculture-statistics`); the file is served as `application/vnd.ms-excel` but is really xlsx. CC BY 4.0, stated inside the workbook.

- **au-trade**: Add **forest and wood products**. The AFWPS exports archive (agriculture.gov.au asset 1038281, a ~109 MB CSV covering 1988-89 → 2024-25: woodchips, logs, sawnwood, paper by destination) is straightforwardly an expansion of existing merchandise-trade coverage. Rejected as a standalone "Timber" site on 2026-08-08 for that reason. The part that is NOT au-trade, and would be the only justification for a separate site later, is the domestic production series: **Australia's native-forest hardwood log harvest collapsed 75% in 28 years — 9,286,600 m³ (1996-97) → 2,312,200 m³ (2023-24) — while hardwood PLANTATION logs went 150,500 m³ → 6,046,000 m³, a 40-fold rise, taking plantations from 1.6% to 72% of hardwood logs.** Tidy long-format xlsx (Plantations / Volume of production / Value of production sheets, 1938→), CC BY 4.0. Same rotating-asset-id trap; note the live path is `/forests/`, not the older `/forestry/`, which 404s.

- **patterns**: Extract a reusable **real-terms deflator** helper. Three separate 2026-08-08 candidates (farm economics, seafood, timber) each needed an ABS CPI series to turn nominal dollars into honest ones, and each would have re-derived it. au-inflation already holds a verified CPI spine; expose it as `patterns/cpi.ts` + a documented SDMX fetch so any site can add a real-terms toggle without re-sourcing, and so every site's real-terms numbers agree with every other site's.

- **NOT-YET-BUILT, worth keeping (these are genuinely new sites, not expansions — they simply lost the 2026-08-08 selection):** (a) **Honours** — all 289,683 publicly gazetted Australian honours since the Imperial era via the PM&C Azure Search JSON API (`POST` with `Origin: https://honours.pmc.gov.au`, `@odata.count` = 289,683), CC BY 4.0, carrying a real finding: *postcode 2088 Mosman holds 326 Order of Australia awards and 3142 Toorak 325, against 15 in 2770 Mount Druitt and 11 in 2168 Green Valley.* (b) **Language Map** — ABS Census G13/T10 by SA2 across 2011/2016/2021: *the single most-spoken non-English language changed in 952 of 1,995 measurable SA2s in a decade; Italian led 522 SA2s in 2011 and 214 in 2021.* Note it is a 5-yearly source, so a cron does nothing until mid-2027. (c) **Court Delay** — RoGS Section 7: *the share of pending criminal cases older than 12 months rose 17.0% → 36.3% in the Supreme courts, 2015-16 → 2024-25.* (d) **FOI Scoreboard** — OAIC agency FOI data, 43 years: *personal-information requests are refused 18.6% of the time against a much higher rate for everything else*; has no geography, so it would need a waiver of the map standard. (e) **Petrol Cycle** — QLD/NSW station-level fuel price history, CC BY 4.0, the largest consumer audience of the batch; its brand leader/follower finding was computed on only two hike waves and needs a proper multi-year test before it could carry a site.
